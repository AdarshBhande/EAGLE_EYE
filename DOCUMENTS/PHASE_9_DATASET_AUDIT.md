## 6. Step 5 — OCR Assessment & Limitations

### 6.1 Requirements
Real cabinet inspection requires reading:
- Component body tags (e.g., `PS12`, `CB43`)
- Panel faceplate labels (e.g., `1CBP03`)
- Wire ferrule marker sleeves (e.g., `X3-01`)

### 6.2 Current Engine Status
- **Tesseract Engine**: Unavailable on OS path (`shutil.which("tesseract") == None`).
- **Heuristic OpenCV Engine**: Active fallback using Otsu thresholding and contour bounding boxes. Emits candidate text boxes with default `0.50` confidence.

### 6.3 Real-World Feasibility
Heuristic contour extraction **cannot** transcribe alphanumeric character sequences from physical ferrule sleeves or thermal printer labels on real panel photos. Genuine OCR recognition on real cabinet photographs will require:
1. Local installation of Tesseract OCR binary or deployment of a fine-tuned text recognition model (e.g., EasyOCR / CRNN / PaddleOCR).
2. High-resolution crop preprocessing (contrast stretching, adaptive thresholding, super-resolution scaling).

## 8. Step 7 — Dataset Requirements & Roadmap to AI Readiness

To unblock genuine AI model training for EAGLE EYE, the following dataset collection and annotation pipeline must be executed:

### 8.1 Required Data Collection (Minimum Viable Dataset)
- **Minimum Cabinet Images**: 200–500 high-resolution photographs of industrial electrical panels.
- **Variability Requirements**:
  - Lighting: Standard shop-floor LED, dim panel interior, directional flash.
  - Angles: Direct orthographic front view, 15°–30° off-axis perspectives.
  - Panel Configurations: Varied DIN rail layouts, wire duct densities, component brands (Siemens, Schneider, ABB, Phoenix Contact).

### 8.2 Annotation Specifications
- **Format**: YOLO v8 format (`data.yaml`, `train/images`, `train/labels`, `val/images`, `val/labels`).
- **Bounding Boxes**: Bounding boxes enclosing every power supply, breaker, terminal block, component label, and wire ferrule.
